# Assignment 4: Dead or Wounded

A Java Swing implementation of the four-digit deduction game. The player uses
dead and wounded feedback to discover a secret code containing four distinct
digits.

## Run

```bash
cd assignment4
./run.sh
```

## Test

```bash
./test.sh
```

See `ASSIGNMENT_EXPLANATION.md` for the rules, scoring algorithm, class design,
GUI behavior, complexity analysis, tests, and presentation notes.
