# Assignment 3: Ayo Olopon

A complete Java Swing implementation of the traditional Yoruba sow-and-capture
board game. It supports local two-player play and a minimax computer opponent.

## Run

```bash
cd assignment3
./run.sh
```

## Test

```bash
./test.sh
```

See `ASSIGNMENT_EXPLANATION.md` for the rules, board representation, algorithms,
GUI design, artificial intelligence, tests, and presentation notes.
